1. adb 运行时来源

本应用的 lib/arm64-v8a/libadb.so 及同目录下的共享库，来自 Termux 官方软件仓库
固定的 android-tools 37.0.0p1-3（arm64）及其依赖包，不从任何参考 APK 提取。
入口 adb 的版本为 Android Debug Bridge 1.0.41 / 37.0.0p1-android-tools。

固定的 .deb URL、SHA-256、逐文件来源和最终文件 SHA-256 见源码仓库的
tools/adb-runtime.lock。详细来源、打包修改、组件与许可证对应关系见 APK 内的
assets/licenses/TERMUX-ADB-RUNTIME.txt，各上游许可证全文位于
assets/licenses/runtime/。

为适应 Android APK 的原生库命名，只截短了 zlib/zstd 的 DT_NEEDED 字符串版本后缀，
并把 adb 可执行文件打包为 libadb.so；没有修改 adb 或共享库的代码。除 adb 外，
本应用没有复用任何第三方 ADB 界面、批量操作或通用 shell 功能。

2. 本应用

本应用使用独立生成的签名密钥，不使用任何收录应用的发布密钥。它只执行固定的
连接、安装、授权、启动、验收和卸载步骤；不索取家长 PIN，不使用 WebView，
不加载远程网页；原生代码只访问官方下载地址，不上传设备数据，不向用户或第三方
提供任意 adb shell 接口，也不接受任意包名。

应用通过 ADB 在用户自己的电视上执行固定操作。安装、卸载、默认桌面切换和
高风险权限都需要用户在界面或电视系统设置中明确确认；应用不会静默开启权限，
也不会卸载电视自带桌面或系统应用。

CleanYourTV 手机版是一个独立 APK：应用只从 cleanyour.tv 页面链接的官方
GitHub Release 解析、校验并交给系统安装器，安装目标是手机，必须由用户在
系统弹窗中确认。本应用不内嵌、不重新托管、不再分发任何收录应用的 APK。

日志可能显示用户输入的电视局域网 IP；分享日志前请自行检查。应用不把配对码、
签名密码或家长密码写入日志。

本应用不是 Termux、Google 或 AOSP 的官方应用。Termux、Android 及其他名称
是其各自权利人的商标。

3. 无担保

本程序按“现状”提供，不附带任何明示或暗示担保。安装前请自行确认电视型号、
系统版本和数据备份；安装流程遇到签名冲突时会停止，不会自动卸载电视上的现有应用。
只有用户明确确认的卸载操作才会卸载对应应用并删除其数据。
