## 1. 产品定位

**工具市场是一个精选电视应用市场，不是“桌面安装器”。**

用户在首页像逛手机厂商应用市场一样浏览、比较、安装和管理电视工具：

```text
浏览特色 → 选择应用 → 连接电视 → 下载并校验 → 安装
         → 权限引导 / 默认桌面接管 → 验收 → 卸载或更新
```

当前目录：

| 分组 | 应用 | 核心价值 |
| --- | --- | --- |
| 热门桌面 | PlanYourTV | 专业儿童桌面、答题系统、时间管理 |
| 热门桌面 | Aerial | 去广告、tvOS 风格、不停用系统桌面 |
| 热门桌面 | Quiet TV | 极简安静、可配置、无推荐流 |
| 热门桌面 | HaloTV | 独立包名、可与 Aerial 共存 |
| 热门桌面 | CleanYourTV | 精简桌面、响应更快、系统清理（需电脑） |
| 热门工具 | 题了个题 StudyOnTV | 答题解锁电视时间、家长面板、本地运行 |

### 要解决的问题

把“打开电脑 → 找官方文档 → 复制豆包 / Agent 指令 → 开 ADB → 下载 APK → 逐条执行 adb → 自己验收”的长流程，收进一部手机；同时保留应用市场最重要的能力：**先看清它是什么，再决定装不装。**

### 非目标

- 不做电视端 App；安装器在手机上，通过局域网 ADB 操作电视。
- 不做 root、刷机、恢复出厂。
- 不卸载、不停用电视自带桌面或系统应用。
- 不静默授予悬浮窗、无障碍、使用情况访问或设备管理员。
- 不把 CleanYourTV 包装成“一键去广告”；官方没有可下载 APK。
- 不内嵌或重新分发题了个题 APK；只链接官方下载渠道。

## 2. 用户与场景

### 典型用户

- 想让电视更干净、去掉广告和推荐流，但不想碰终端；
- 有孩子的家庭，想控制观看时长，或把学习任务和电视时间绑定；
- 已有 Android 手机，不想为装一个电视应用再开电脑；
- 愿意按引导开启电视 ADB，但看不懂 `INSTALL_FAILED_*`。

### 三个关键时刻

1. **选什么：** 六个项目看起来都和“电视桌面 / 儿童管理”有关，需要一眼看出差异和风险。
2. **连不上：** 不知道 IP、找不到 ADB 入口、看到 `unauthorized` 会慌。
3. **装完后：** 桌面要确认 Home 是否接管；工具要确认权限是否开启、HOME 是否被误改、数据删除是否可接受。

设计必须在这些时刻给出可执行答案，而不是只展示一个“安装”按钮。

## 3. 设计原则

1. **像应用市场一样先比较。** 每个应用有独立卡片、品牌图标、状态徽章、三条特色 chip 和说明；不是一行只有名字和按钮的清单。
2. **两栏主导航 + 抽屉。** 底部固定「工具市场 / 我的电视」；工具市场承载发现与安装，我的电视承载连接、初始准备、设备与系统配置。版本、权限、日志、设置继续用底部抽屉，不增加更多一级 tab。
3. **状态优先于按钮。** 先看到“已连接 / 未安装 / 已安装 / 默认桌面 / 需电脑”，按钮随状态变化。
4. **先解释，再动手。** 安装前说明会做什么；卸载前说明会删什么；工具与桌面的 HOME 行为要显式区分。
5. **官方源优先，结果可验证。** 下载顺序、版本、包名、SHA-256 和验收结果都必须可见；不能只报 `Success`。
6. **明亮、克制、可信。** 白底、浅蓝强调色、轻柔阴影、少量语义色；视觉接近手机厂商应用市场，而不是极客终端工具。
7. **权限最小化。** 特别针对题了个题：必需权限给引导，可选权限明确标注，设备管理员绝不自动开启。

## 4. 信息架构

底部固定两个一级入口，对应两类核心任务：

```text
工具市场（Tab 1）                        我的电视（Tab 2）
├─ 搜索                                 ├─ 未连接：初始准备
├─ 分类：全部 / 桌面 / 工具               │   ├─ 3 步建立局域网连接
├─ 电视状态卡 ───────────────────────→  │   ├─ 上次连接
├─ 热门桌面（5 张应用卡）                  │   ├─ 无线调试 / 网络 ADB / USB 说明
├─ 热门工具（1 张应用卡）                  │   └─ 选择连接方式
├─ 安全安装边界                          └─ 已连接：设备仪表盘
└─ 好工具，值得被看见                         ├─ 设备信息 / 连接检查
        ↓ 全屏详情页                         ├─ 已安装应用
介绍 / 截图 / 安装 / 卸载 / 权限引导            ├─ 系统配置
                                                └─ 断开连接
设置（右上角）
```

- 连接电视、无线配对、网络 ADB、USB 说明都进入底部抽屉，不跳整页。
- 设置仍然放右上角，不占一级导航。
- **「初始准备」是「我的电视」未连接时的状态，不是常驻 tab。** 连接成功后，同一个 tab 直接变成设备仪表盘。
- **「系统配置」是已连接仪表盘里的一个分区。** 全局设置仍走右上角设置抽屉。
- 应用详情是独立全屏页面（`detailHost` 覆盖层）：顶部返回与名称、官方截图轮播、介绍与安装选项、固定底部操作栏。安装进度与结果仍用底部面板，连接与设置也继续用底部面板。

### 为什么是「工具市场 / 我的电视」

- 用户只有两条主线：**找工具、装工具**，以及**连电视、管电视**。两个 tab 一一对应。
- 若把「初始准备」做成一级 tab，连接成功后它会变成空入口，还会与「我的电视」重复。
- 若把「系统配置」做成一级 tab，会让“连接电视”这个最高优先级动作落到二级，与“先连接，再安装”的产品顺序冲突。
- 导航标签不随连接状态变化，只切换内容状态，用户心智更稳定。

## 5. 工具市场（Tab 1）

### 5.1 顶部

```text
┌────────────────────────────────┐
│ ▣ 工具市场                  ⚙  │
│   Tool Store · 精选电视工具    │
└────────────────────────────────┘
```

- 左侧是 42dp 蓝色渐变 Logo + 两行品牌；工具市场 tab 为 `工具市场`、`Tool Store · 精选电视工具`，我的电视 tab 为 `我的电视`、`连接、初始准备与设备管理`。
- 右侧 38dp 描边图标按钮，打开设置；两个 tab 都保留。
- 顶部不使用大 banner；首屏必须尽快露出搜索、设备状态和应用卡。
- 底部导航保持固定：左侧「工具市场」，右侧「我的电视」；在线状态用电视图标右上角小圆点表示，不改变导航文案。

### 5.2 搜索与分类

- 搜索框占满整行，placeholder：`搜索桌面、答题、清理…`。
- 搜索覆盖：名称、英文名、tagline、描述、包名、feature chips。例如“答题”命中 PlanYourTV 和题了个题。
- 有输入时显示右侧清除按钮；无结果显示空状态和“清除筛选”。
- 分类 chip：`全部 6`、`桌面 5`、`工具 1`；选中为蓝色实心胶囊，未选中为白底描边。
- 搜索和分类可组合：工具分类下搜“答题”，只显示题了个题。

### 5.3 电视状态卡

**已连接：**

```text
┌─────────────────────────────────────┐
│ [TV]  ● 已连接 · ADB 已授权       › │
│       小米电视 · MiTV-MFTR0          │
│       192.168.1.100 · 默认桌面 PlanYourTV │
└─────────────────────────────────────┘
```

**未连接：**

```text
┌─────────────────────────────────────┐
│ [Wi-Fi] ● 未连接电视         [连接] │
│         连接你的电视                 │
│         同一 Wi-Fi · 自动发现或输入 IP │
└─────────────────────────────────────┘
```

- 整卡可点，两个状态都切到「我的电视」tab：已连接进入仪表盘，未连接进入初始准备；连接操作再从该页发起。
- 未连接时，所有安装 CTA 变成 `先连接`，点击直接打开连接抽屉，避免先跳页再操作。
- 默认桌面名称来自实际读取；工具安装不应改变它。
- 卡片底部文案：已连接显示 `IP · 默认桌面`，未连接显示 `同一 Wi-Fi · 无线配对或网络 ADB`，右侧动作是 `去准备`。

### 5.4 分区与计数

```text
热门桌面                2 / 5 已安装
换一个更安静、更顺手的电视首页

[PlanYourTV 卡片]
[Aerial 卡片]
...

热门工具                0 / 1 已安装
不只换桌面，也让电视更好用

[题了个题 卡片]
```

- 分区标题 16sp / 680；说明 10sp；右侧计数 9.5sp。
- 分区只在有筛选结果时显示；某一分区被过滤为空则整段隐藏。
- 安装状态变化后，计数与卡片徽章即时更新。

### 5.5 应用卡片结构

卡片是首页最重要的信息单元。采用 **白底、20dp 圆角、14dp 内边距、轻阴影**，新上架应用使用极淡橙色渐变。

```text
┌──────────────────────────────────────┐
│ [题]  题了个题  [新上架]      [安装] │
│       StudyOnTV · 答题换电视时间      │
│                                      │
│ 先学习，后娱乐：孩子答题解锁电视时间，│
│ 家长扫码管理题库与规则。              │
│                                      │
│ (答题解锁) (家长面板) (本地运行)      │
│ ─────────────────────────────────    │
│ ⓘ 不是桌面，不会更改默认 HOME；       │
│   权限可在电视上按需开启。            │
└──────────────────────────────────────┘
```

**结构顺序固定：**

1. 46dp 品牌色图标（字母 / 汉字 + 浅色 tint 底）；
2. 名称 + 状态徽章；
3. 英文名 / tagline；
4. 右上角或行尾动作按钮；
5. 一句差异化描述；
6. 2–3 个特色 chip；
7. 可选的卡片级风险提示。

**为什么用卡片而不是列表行：**

- 用户需要比较“儿童答题”“去广告”“需电脑”“不改 HOME”等差异，行式列表承载不了这些维度；
- 应用商店式卡片能同时表达品牌、功能、状态和安装入口；
- 每张卡不需要点进去就能完成初筛。

### 5.6 动作按钮状态

| 应用状态 | 卡片按钮 | 点击行为 |
| --- | --- | --- |
| 未安装、已连接、可安装 | `安装` 蓝色实心 | 打开详情安装区 |
| 未安装、未连接 | `先连接` 白底描边 | 打开连接抽屉 |
| 已安装 | `管理` 白底描边 | 打开已安装详情 |
| 需电脑 | `安装指引` 琥珀色浅底 | 打开 CleanYourTV 引导 |
| 安装中 | 不回到首页；进度抽屉锁定 | 取消安装 |
| 不支持 | 禁用 | 解释最低系统 |

安装网络请求期间不提供“后台安装”假入口；关闭抽屉前必须确认取消。

### 5.7 徽章系统

| 徽章 | 语气 | 规则 |
| --- | --- | --- |
| `默认桌面` | 绿色 | 该应用是当前默认 HOME，桌面类才显示 |
| `已安装` | 绿色 | 已安装且非默认桌面 |
| `未安装` | 灰色 | 详情页状态 |
| `新上架` | 橙色 | 近期收录；卡片可有轻微暖色渐变 |
| `测试版` | 琥珀色 | 官方标记 prerelease 或项目自述 |
| `需电脑` | 琥珀色 | 手机无法独立完成安装 |
| `工具应用` | 蓝色 | 工具类详情页，强调不是桌面 |

徽章只做补充，不能是唯一语义：同样状态必须有文字，例如按钮本身显示“安装 / 管理”。

### 5.8 安全说明与收录入口

**安全安装边界**（白底紧凑卡）：

```text
⛨ 安全安装边界
只动第三方应用 · 安装前校验 · 桌面类卸载前切回原桌面
```

**收录入口**（浅蓝描边卡，可整卡点击）：

```text
⊕ 好工具，值得被看见             收录说明
  提交推荐，由站长审核后收录上架
```

这两块放在应用列表之后，不抢占应用曝光；安全边界是常驻安心信息，收录入口是持续扩展的市场入口。

### 5.9 空状态

```text
没有找到相关工具
换个关键词，或查看全部已收录工具。
[清除筛选]
```

- 空状态不显示“加载失败”；
- 不隐藏安全说明，但收起空的分区；
- 清空搜索与筛选后恢复全部 6 个应用。

## 6. 应用详情

### 6.1 通用头部

```text
┌────────────────────────────────────┐
│ [题] 题了个题                    ✕ │
│      StudyOnTV                     │
│      答题换电视时间                 │
│      [未安装] [新上架] [工具应用]   │
│                                    │
│ (答题解锁) (家长面板) (本地运行)    │
```

- 46dp 应用图标、名称、可选的 Latin 名、tagline、状态徽章、feature chips。
- 关闭按钮固定在右上角。
- 不同应用进入不同 body；不是所有应用都显示同一个“版本 + 安装”模板。

### 6.2 桌面未安装：版本与安装

适用于 PlanYourTV / Aerial / Quiet TV / HaloTV。

```text
选择版本
[ 标准版 ] [ Guard ] [ Lite ]
推荐标准版 · 约 7.7 MB · Android 5.0+

最新版本   2.17
包名       app.orchard.tv
下载顺序   官方 → GitHub
来源       官方 / GitHub

安装选项
安装后设为默认桌面        ○──
安装后校验               必选
  SHA-256（官方提供时）、包名、版本、签名

[ 安装到电视 ]
[ 复制官方 Agent 指令 → ]
```

规则：

- 版本来自项目配置；不显示不存在的变体。
- `设为默认桌面` 默认关闭；用户明确勾选才尝试切换，关闭时安装完成后不碰 HOME。
- 只展示普通用户能理解的验证券，ADB 命令收在“复制 Agent 指令”/日志展开里。
- 安装须知按应用变化：PlanYourTV 说明 Guard；Quiet TV 标注测试版；HaloTV 提示权限不继承；Aerial Lite 提示低版本兼容。
- 页面底部固定小字：可以共存，但不要同时开启多个 Home Guard。

### 6.3 桌面已安装：打开与管理

- 顶部状态显示 `已安装`，默认桌面加 `默认桌面` 徽章。
- 主操作：`在电视上打开`、`设为默认桌面`（已是默认时禁用或显示为状态）。
- 信息行：当前版本、包名、版本档、默认桌面、来源。
- 针对项目显示卸载数据警告。
- 卸载是文字级危险操作，放在底部；先弹确认框，不在第一屏放巨大红色按钮。
- CleanYourTV 已安装时按“电脑构建”逻辑显示，不伪装成普通一键安装。

### 6.4 工具未安装：题了个题安装区

```text
先学习，后娱乐：孩子答题解锁电视时间，
家长扫码管理题库与规则。

选择版本
[ TV 标准版 ] [ TV 本地版 ]
推荐 · 在线 AI / 语音 · 约 3.5 MB · Android 5.0+

最新版本   0.5.6 · 2026-11-24
包名       com.studyontv.tv
最低系统   Android 5.0+
下载顺序   蒲公英官方更新 / Gitee / GitHub · 只选最新版
许可证     源码可见 · 仅个人使用

安装选项
安装后打开权限引导        ●──
  悬浮窗、使用情况访问；无障碍与自启动可选
安装后校验                必选
默认桌面                  不更改
  保持 PlanYourTV；工具应用不改 HOME

[ 安装到电视 ]
[ 复制官方 Agent 指令 → ]
```

关键差异：

- **没有“设为默认桌面”开关**；明确显示“默认桌面不更改”。
- 增加权限引导开关；权限只打开设置页，不静默授权。
- 许可证提示为警示色，说明不是 OSI 开源。
- 版本说明区分“在线 AI / 语音”和“零公网 / 隐私优先”。
- 标准版提示会联网使用在线能力；本地版提示在线能力不可用。

## 7. 题了个题专题设计

题了个题是第一个“非桌面”条目，它的设计必须证明工具市场可以收纳不同类型。

### 7.1 卡片表达

- 名称：`题了个题`；副行：`StudyOnTV · 答题换电视时间`。
- 徽章：`新上架`；不显示 `桌面`。
- 特色：`答题解锁`、`家长面板`、`本地运行`。
- 卡片提示：`不是桌面，不会更改默认 HOME；权限可在电视上按需开启。`
- 使用新上架暖色渐变，和 5 个桌面卡区分，但保持同一卡片结构。

### 7.2 权限引导

权限抽屉逐项展示，禁止一次性“全部允许”：

| 权限 | 必需性 | 文案策略 |
| --- | --- | --- |
| 显示在其他应用上层 | 核心 | 到时间显示学习页和解锁提醒；部分电视入口被精简，可复制 AppOps 命令 |
| 使用情况访问 | 核心 | 识别前台应用与使用时长；跳转系统设置由用户确认 |
| 无障碍服务 | 可选 | 增强应用切换识别；不开启也能使用核心功能 |
| 开机自启动 / 后台运行 | 可选 | 重启后恢复计时；受厂商后台清理影响，不承诺所有机型 |
| 设备管理员 | 可选 + 高风险 | 仅用于防卸载；安装器绝不自动开启，卸载前必须取消 |

抽屉底部提供“复制 ADB 权限命令”，方便高级用户在有 `adb` 的电脑或同一手机的 Shizuku / 本地 ADB 环境执行。命令区与普通用户说明分开。

### 7.3 安装步骤

```text
检查电视与空间
下载安装包        蒲公英官方更新 / Gitee / GitHub，只选最新版
校验 SHA-256
安装 APK          com.studyontv.tv
打开权限引导      可选（按安装选项）
启动并验收        检查应用是否正常启动；不更改默认桌面
```

- 工具流程**没有**“设为默认桌面”步骤。
- 安装过程中显示“不会更改默认桌面”。
- 成功页显示默认桌面“未更改”，并且不出现“切回原桌面”类操作。

### 7.4 卸载步骤

```text
停止计时与悬浮层
检查设备管理员
卸载 APK
验收默认桌面与包状态 → 确认 HOME 未发生变化
```

- 卸载前警告：题库、学习记录、观看时长、家长规则全部删除。
- 如果检测到启用的设备管理员，卸载器不能强行移除；必须提示在电视系统设置中先取消。
- 卸载完成页显示“设备管理员：未更改 · 建议复查”，避免误以为系统授权已被清理。
- 卸载成功后不应弹出“恢复原桌面”，也不应修改 `state.defaultHome`。

### 7.5 家长面板

- 面板地址：`http://<电视IP>:8099/`，`/admin` 为同一管理页。
- App 中仅展示地址和说明，不保存管理密码，不代理请求。
- 未来可在已安装工具详情增加：
  - `复制家长面板地址`
  - `用浏览器打开`（仍需手机与电视同一局域网）
- 由于端口只在局域网开放，增加安全提示：不要将 8099 暴露到公网。

### 7.6 许可证与来源

- 来源顺序：同时读取蒲公英官方更新通道、Gitee 官方镜像与 GitHub 官方 Release，只使用版本最新的源；同版本时按 Gitee → 蒲公英 → GitHub 排序。
- TV 标准版可使用蒲公英官方更新通道（即应用自身的更新接口）；TV 本地版只从 Gitee / GitHub 获取，保持零公网语义。
- Gitee 镜像可能滞后；滞后时选择蒲公英或 GitHub 最新版，并在日志中如实说明，不能为了速度装旧版。
- 蒲公英分发的 0.5.6 TV 标准版与 GitHub Release 已核对为同一 APK（SHA-256 `df5463…0153`）；官方索引未提供哈希时仍核对包名、版本与固定签名证书。
- 许可证：Source Available License — Personal Use Only。
- 工具市场不内嵌、不再分发 APK；展示“源码可见 · 仅个人使用”警示。

### 11.4 连接抽屉

连接抽屉是底部大抽屉，顶部固定三种方式：`无线调试 / 网络 ADB / USB 调试`。

公共信息：

- 手机与电视在同一 Wi-Fi；
- ADB 只连局域网，不走下载代理；
- 首次连接必须在电视上允许，手机不会代替用户点“允许”；
- 扫描到设备后由用户点「连接」，不自动连接；手动输入 IP 默认折叠在“手动输入 IP（高级）”中，避免与扫描结果混淆。

- IP、配对端口、6 位配对码三项校验；配对码只保留数字，最多 6 位。
- 配对码不写入日志、不进剪贴板、不持久化；配对完成即从表单移除，连接完成后状态中清空。
- 局域网扫描同时使用 mDNS 广播与 5555 端口探测；列出所有已开启 ADB 的候选设备（名称、地址、来源），每行右侧直接提供「连接」按钮，点击即直接连接（无需先“选择”再点第二次）。首次无线调试仍需配对码；未开启 ADB 的设备不会出现在列表里。
- 手动输入 IP 默认折叠；扫描失败或高级用户需要时再展开。直接连接失败会自动展开表单并保留已填地址，方便继续配对。

- 连接成功后进入授权状态：显示电视端弹窗示意，必须由用户点“我已在电视上允许”。

### 11.5 网络 ADB（兼容模式）

- 适用于开发者在电视端明确开放“网络调试 / ADB over network”的电视，默认端口 5555。
- 表单：IP + ADB 端口 + 扫描当前局域网设备；不需要配对码，但仍需要在电视上允许调试授权。
- 页面必须显示安全警告：**只在自己家的局域网使用；不要做路由器端口转发，不要在公共 Wi-Fi 下开放 5555；ADB 授权等同于电脑调试权限。**
- 成功页不显示“配对码已丢弃”，改为 `网络边界：仅局域网 · 未做端口转发`。
- Android 11+ 没有网络调试入口时，引导回无线调试配对，而不是让用户猜端口。

### 11.6 USB 调试说明

USB 调试不是连接方式，而是电视端开关。应用不能远程打开它，也通常不能把手机当 USB ADB 主机通过数据线装电视应用。

页面必须把“能做 / 不能做”分开：

| 能做 | 不能 |
| --- | --- |
| 在电视上开启开发者选项、USB 调试和网络调试，再用配对码完成一次授权 | 通过手机 App 远程打开这个开关；大多数手机也不能用数据线作为 ADB 主机直接安装 |

电视端 3 步可勾选清单：

1. 打开开发者选项；
2. 打开 USB 调试（有网络调试 / ADB over network 也一并打开）；
3. 首次连接在电视上选择“始终允许”。

- 3 步必须全部勾选，`去无线连接` 才可用；不能假装用户已经完成电视端操作。
- 同时提供“改用网络 ADB（5555）”和“复制步骤”，方便高级用户。
- 底部解释为什么不能数据线直装，避免用户反复插拔电视 USB。

### 11.7 安全与错误映射

| 状态 | 文案 |
| --- | --- |
| 连接超时 | 确认同一 Wi-Fi、电视端调试开关仍开启 |
| 未授权 | 在电视弹窗选“始终允许”，不要反复重连 |
| 配对失败 | 以电视当前显示的配对码与配对端口为准 |
| 端口拒绝 | 可能只支持无线调试配对，查看电视端开启方法 |
| 扫描无结果 | 只探测局域网；必要时展开“手动输入 IP（高级）”，不访问公网 |
| 公共网络 | 不要在公共 Wi-Fi 开放 5555，不做端口转发 |

- ADB 永远直连私网，不走下载代理。
- 调试密钥留在手机本地；应用不读取、不上传电视内容。
- 日志不含配对码、家长 PIN、题库内容或恢复码。
- 真实实现中，连接成功必须以电视端授权和 ADB 状态为准，不能只凭用户点按就报成功。

### 14.6 动效

- 抽屉：240ms，`cubic-bezier(.2,.8,.2,1)`。
- 卡片 hover / 按下：160ms 位移与阴影，不做夸张缩放。
- 进度条：200ms 线性过渡；尊重“减少动态效果”。
- 成功页：300ms 淡入 + 轻微上移，不撒彩带。
- 刷新、下载、连接状态必须有非动画文本兜底。

### 14.7 无障碍

- 所有图标按钮带 `contentDescription` / `aria-label`。
- 状态不只靠颜色，必须同时有文字（“已连接”“已安装”“默认桌面”）。
- 对比度至少 4.5:1；浅灰说明文字只用于辅助信息，不承载唯一关键动作。
- 支持系统字体放大；卡片高度和按钮宽度随文字扩展。
- 卸载确认默认焦点在“取消”。
- 电视是另一块屏幕，手机端不依赖遥控器操作。

## 15. 数据驱动目录

### 15.1 目录条目

原型使用 JavaScript 对象；原生实现使用 Java `UiData` + `Catalog` 固定目录，运行时索引由 `ApkResolver` 解析为结构化 `JSONObject`。关键字段：

```text
id
name / latin / tagline / desc
letter / color / tint / border        // 品牌图标
category: launcher | tool
features: String[]                    // 2–3 个特色
packageName / variants
officialUrl / releasesUrl / repoUrl / giteeUrl
sourceShort / minAndroid / latestVersion / latestLabel
defaultVariant / variants[]
installed / installedVersion / installedVariant
testBuild / needsPc / installable / isNew
setupOnInstall
permissions / permissionGuide[]
permissionCommands
licenseNote
cardNote
agentPrompt
```

未来新增工具时，优先只改目录数据；只有当新工具需要全新的安装 / 权限类型时，才扩展执行器。

### 15.2 桌面与工具的差异字段

| 字段 / 行为 | 桌面 | 工具 |
| --- | --- | --- |
| `category` | `launcher` | `tool` |
| HOME role | 可参与 | 不参与 |
| “设为默认桌面” | 可显示 | 不显示 |
| 安装验收 | 读回版本；可选 HOME 切换需电视确认 | 读回版本，默认 HOME 不变 |
| 卸载前置 | 不是当前默认 HOME | 不是当前默认 HOME；提示设备管理员需先手动取消 |
| 卸载验收 | 包已消失，不产生空 HOME | 包已消失，HOME 未更改 |
| 权限引导 | 可选（按项目） | 通常需要，逐项说明 |

### 15.3 下载源

```text
PlanYourTV:  官网 version.txt + 固定发布文件
Aerial:      官网 version.txt → GitHub 官方 Release 备用
Quiet TV:    官方 latest.json → 官方 GH 镜像（ghfast / gh-proxy / v4）→ GitHub Release 资产
HaloTV:      官网版本页解析 → GitHub 官方 Release 备用
CleanYourTV: 官方页面（无 APK / 电脑构建）
StudyOnTV:   蒲公英官方更新 + Gitee 官方镜像 + GitHub 官方 Release，只选最新版
```

- 首版目录固定在 `Catalog`，每个应用由 `ApkResolver` 的专用解析器读取官方索引；URL 不接受 UI 或远程输入。
- 官方索引未提供 SHA-256 时仍强制校验包名、版本与固定签名证书；提供 SHA-256 时逐字节校验。
- 下载只允许官方主机和官方资产路径；GitHub 重定向只允许官方 CDN，Gitee 只允许官方附件域名，蒲公英只允许安装跳转路径及其官方 CDN，Quiet TV 只允许其官方更新器公布的 GitHub 代理主机。网络失败才切换备用源，完整性校验失败立即停止，不回退到旧缓存。
- 连接中断时按 HTTP Range 断点续传，最多 4 次；续传前后重新计算哈希，失败不会伪装成成功。
- 工具市场只下载官方 Release，不缓存并重新分发 StudyOnTV APK。
- Gitee / 官网链接仍可在详情与说明中展示，但不会在没有对应校验信息时偷偷切换来源。

### 15.4 收录与未来远程目录

未来可增加远程目录，但首版保持内置：

1. 站长用模板收集项目信息；
2. 人工核对来源、版本、许可证、权限与恢复方式；
3. 审核通过后进入目录配置；
4. 客户端定期拉取已审核目录，展示“新上架 / 更新”；
5. 客户端不执行远程脚本，只接受结构化字段和固定来源类型。

远程目录必须签名 / 校验；禁止远程指挥客户端静默授予权限、卸载系统应用或修改 HOME。

## 16. 原生 Android 实现

### 16.1 技术栈

已落地的实现：

- 纯 Java + XML，单 `MainActivity`；系统 `LinearLayout` / `ScrollView` / `Dialog` / `TextView` / `EditText` / `Switch` 等框架控件；
- 自绘 `LogoView` / `LineIconView` / `FlowLayout`，不引入图标库或 Material；
- `ExecutorService` + `Handler(Looper.getMainLooper())` 处理下载、ADB、扫描等耗时任务；
- `HttpURLConnection` 官方源下载器，HTTPS、精确主机白名单与重定向限制；
- 内置 Termux `android-tools` arm64 ADB 运行时，`AdbClient` 启动，`DeviceSession` 封装配对 / 授权 / 巡检 / 卸载；
- 构建端直接使用 `aapt2` + `javac` + `d8` + Python `zipfile`，本机 `zipalign` / `apksigner`，**不使用 Gradle / AndroidX / Compose / WebView**。

### 16.2 分层

```text
MainActivity + XML 屏幕
    ├─ AppDetailPage（detailHost 全屏页面层）→ SheetPanel（进度 / 结果）
    └─ ConnectSheet / Settings（原生框架 Dialog 面板）
    ↓
UiData + Catalog（固定目录与文案）· MediaCatalog（官方图标 / 截图映射）
    ↓
ApkManager（安装编排、下载后校验、读回验收）
    ├─ ApkResolver → HttpDownloader
    └─ DeviceSession → AdbClient → bundled libadb.so
    ↓
LanScanner（mDNS + 私有网段 5555）
```

所有回调回到主线程；安装 / 卸载都有全局忙状态，防止并发操作互相踩踏。

### 16.3 安装流程

```text
确认电视 serial 状态为 device
    ↓
ApkResolver 读取官方索引（版本 / URL / SHA-256 / 签名证书）
    ↓
HttpDownloader 下载（主机白名单、大小上限、逐块 SHA-256）
    ↓
ApkManager 用 PackageArchiveInfo 检查包名、minSdk、签名证书、版本
    ↓
adb -s <serial> install -r
    ↓
从电视读回已安装版本（读不到就报失败）
    ↓
桌面且用户勾选“设为默认桌面” → DeviceSession.setHome → 读回确认
工具 → 不调用 setHome，默认 HOME 保持不变
```

工具安装计划不包含 HOME 切换；桌面安装也必须由用户明确勾选。任何一步失败都给出具体原因，不把 `ADB Success` 当作完整验收。

### 16.4 卸载执行器

- 目标包名必须来自固定 `Catalog`，且电视端确实已安装；不允许界面传入任意包名。
- 目标是当前默认桌面时直接拒绝，提示先到「我的电视」恢复原桌面，绝不制造空 HOME。
- 执行 `pm uninstall <package>` 后重新读取 `pm list packages`，确认包已消失；否则报失败。
- 工具与桌面都只移除第三方应用本身，不触碰系统桌面和系统应用。
- CleanYourTV 不显示一站式卸载按钮，只提示先在电脑上执行官方 `restore.sh`，再按官方说明处理。
- 所有 ADB 输出用于错误说明前会做脱敏与截断，不泄露配对码或敏感路径。

### 16.5 安全

- ADB 只在局域网连接；不提供公网端口映射。
- 下载器只允许官方 HTTPS 主机和官方 GitHub 资产路径；ADB socket 直连私网。
- 不提供卸载 / 停用系统桌面的入口，不把界面输入变成 shell 命令。
- 设备管理员、无障碍、悬浮窗、使用情况访问等权限不提供静默授权捷径。
- 日志不包含配对码、签名密码、PIN、家长密码、题库内容、恢复码。
- 固定目录 + 签名证书锁定 + 包名 / 版本校验；后续远程目录必须签名 / 校验，禁止变成任意命令执行。

### 16.6 原型调试

原型支持 URL 调试视图：

```text

?view=connect&mode=classic         网络 ADB 表单

?view=connect&mode=wireless&phase=paired
?view=connect&mode=wireless&phase=authorize

?view=detail&app=studyontv
?view=permissions&app=studyontv

?view=uninstall&app=studyontv&installed=studyontv
```

### 16.7 全屏应用详情页（0.2.0，卸载与官方恢复 0.2.4）

详情页不是新 Activity，也不是全屏 Dialog，而是 `MainActivity` 根布局里的 `detailHost` 覆盖层，由 `AppDetailPage` 填充：

- 复用已连接的设备会话、已安装列表与刷新回调，避免跨 Activity 搬状态。
- 关闭时移除页面视图并恢复市场原来的滚动位置。
- 返回键优先关闭详情页；安装 / 卸载进行中拒绝关闭并提示保持前台。
- 连接状态变化（`attachDevice` / `clearDevice`）会重建详情页底栏和安装选项。
- 切换底部 tab 会立即关闭详情页，避免覆盖层残留。

页面结构：

```text
┌────────────────────────────────────┐
│ ←   PlanYourTV              [精选收录] │  56dp 顶栏 + 细分割线
```

底栏状态：

| 条件 | 主操作 | 说明 |

| 已连接 + 未安装 | `安装到电视` | 使用所选版本与 HOME 开关 |

卸载入口与官方恢复（0.2.4）：

- **详情页底栏**：已安装时固定显示危险色 `卸载`，紧邻 `打开应用`；不再依赖滚动到下方的管理区。
- **已安装卡片**：`已安装到电视` 区增加整行宽度的 `卸载 {应用名}` 按钮，并注明恢复顺序。
- **「我的电视」已安装卡片**：每行只保留一个 `卸载` 按钮，不再显示 `在电视上打开 / 详情 / 先切回原桌面`；点卡片仍可进入详情页。
- **默认桌面直接卸载**：不再要求用户先手动切回桌面。卸载确认后由 `DeviceSession` 按官方恢复顺序自动执行：
  1. 发送 Guard 配置广播，停止该应用继续改回设置；
  2. 撤销通知监听、无障碍、悬浮窗、使用情况等 AppOps / 权限；
  3. 恢复被该应用接管的屏保、TCL 开机应用、海信 `persist.vt.use_home_pkg` 设置；
  4. 找到安装前记录的原桌面；如果原桌面已被停用，先用 `pm enable` 恢复；
  5. 用 `cmd package set-home-activity` 切回原桌面并读回确认；
  6. 确认 HOME 已恢复后才执行 `pm uninstall`，最后再次读回 HOME 和已安装状态。
- **安全底线**：如果电视上找不到可用的原桌面，或系统没有确认切换，卸载会在删除应用前停止并说明原因，绝不把主页留在空状态。
- **多个已安装版本**：先弹出底部面板逐个列出包名与版本，由用户选择；每一项都提供 `卸载这个版本`。
- **工具（StudyOnTV）**：直接卸载，只删除题库、规则和使用记录，不读取或修改 HOME。
- **CleanYourTV**：永远没有卸载按钮。它会停用系统项，必须先在电脑上运行官方 `restore.sh` 恢复被停用的应用和原桌面，再按官方说明卸载；手机端不猜测恢复列表。
- 卸载确认与结果沿用 `SheetPanel`：真实进度、可重试、完成后刷新市场与设备页；结果会分别说明“默认桌面已切回”或“系统设置已恢复”，不把 ADB `Success` 当成最终成功。
- 所有卸载目标来自固定精选目录的已安装列表，系统桌面与系统应用永远不会成为卸载目标。

## 17. 待确认的产品决策

1. **CleanYourTV 策略**
   - 当前实现 A：只做官方电脑构建 / 恢复引导和已安装状态展示，手机端不提供一键安装，也不提供绕过官方恢复的卸载；
   - B：内置社区构建的 launcher APK（不采用）；
   - C：复刻社区手机版的清理能力（不采用，需要设备列表、恢复记录、签名与安全评审）。
   保持 A，直到官方提供可验证的 APK 与恢复方案。

2. **默认桌面开关默认值**
   当前实现为默认关闭，只有用户安装时明确勾选才尝试切换。安装完成后仍可在详情或「我的电视」中手动切换；未确认就报“未接管”。

3. **工具权限状态读取**
   当前只做逐项权限说明和电视端设置入口，不静默授权，也不把“打开设置页”当成“已授权”。后续若要读取悬浮窗 / 使用情况 / 无障碍实际状态，必须显示“未读取 / 未开启 / 已开启”的真实状态。

4. **代理入口**
   首版不提供应用内下载代理；官方下载走 HTTPS，ADB 永远直连局域网。未来若增加代理，只能影响下载器，不能影响 ADB socket。

5. **批量安装 / 更新检查**
   技术上可行，但桌面 HOME 只有一个，多个 Home Guard 会冲突。建议先逐个安装；更新作为第二阶段。

6. **远程目录与审核后台**
   先内置目录；待收录数量增长后，再建设审核后台与签名目录。
